## What changed for simpler execution

- S07-A shows only Atan making one gesture. S07-B cuts to the two officers listening; no simultaneous three-person performance is required.
- S08-A establishes a beam already supported by two workers. S08-B isolates one small support-hand adjustment. The coordinated lift/walk was removed; the recovery image remains an illustrative reconstruction.
- S06 is a restrained listening shot with a small camera push; the added nod beat is removed. S09 uses one camera truck with a settled gaze. S10 rises for 5.5 seconds, then holds for 1.5 seconds.
- S03 is an editor-built locator; its optional image prompt creates only a paper texture. A dated text-only fallback is specified if the geographic reference is missing.

## Usage and timing

Each shot folder contains full starting-frame prompts for 9:16 and 16:9, an animation prompt or editor instruction, narration text, and shot metadata. Prompts carry the actual subject description rather than relying on aliases alone. Reference IDs are inventory labels, not attached images or working provider tokens. Bind real inspected files to a supported live schema later. No model, cost, preset, frame rate or generation duration has been assumed.

Durations are cut lengths, not supported provider clip lengths or measured speech. Continuous voiceover crosses S07-A/B and S08-A/B; do not record each fragment as an isolated sentence. Record/measure the complete narration before final word alignment. Read 1662 as “solah sau baasath” and 1663 as “solah sau tirsath”; Assamese name pronunciation remains an audio-check task.

All source qualifications are preserved: C07 is attributed to Bhuyan; exact likeness, clothes, actions and sets are reconstruction. The date/appointment wording and 1663 treaty bridge remain unchanged. No new historical research is claimed in this conversion. SOURCE_PLAN.md contains the inherited claim ledger and source links.
